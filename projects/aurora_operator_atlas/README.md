# Aurora Operator Atlas — Offline Interactive Preview

**Status:** illustrative, self-contained UI, noncanonical. No credentials required.

Open `projects/aurora_operator_atlas/index.html` locally in any modern browser.
All styles, interactions, and fixture content are bundled inside that one file.
There's no installation, build step, network API call, service, plugin connection,
runtime session, dependency on ChatGPT or write access.

## What it demonstrates

1. **Overview** — report-origin metrics, existing source capabilities and the
   boundary between saved data, UI projection, isolated simulation and canon.
2. **Mission Control** — 12 historical operator findings, filters, search,
   evidence-safe detail inspector, and 6 selectable build-readiness lanes.
3. **GUMAS Lab** — scenario/intensity/turn controls update a **synthetic**
   stability/risk chart. This is an interface illustration, NOT a GUMAS run.
4. **Canon & ACE** — selectable L1/L2/L3 roles, receipt/determination sequence
   and source links without any canon mutation.
5. **Integration Map** — PR #97/#98/#99 engineering groundwork and the
   cross-repository GPT-6 issue relationship.

## Source accuracy

The Mission Control view uses selected nonrestricted facts from
`reports/analysis/aurora_mission_control_latest.json`, generated
**2026-08-15 05:30:37 UTC**. The file's 'latest' name should not
be interpreted as current operations. The preview intentionally
embeds a small vetted, source-labeled snapshot rather than pretending to
fetch live data. No recovery-review evidence paths, internal recommended
commands or private source fields are presented.

Recorded toolchain findings refer to that report's noncanonical execution
context and are **not** proof of an outage or deficiency on the current
developer machine. Issue links and PR links require deliberate user clicks;
the app itself makes no HTTP requests.

The GUMAS trajectory is generated by small client-side illustrative
equations. It is *not* measured data, a forecast, an engine
run, or a simulation outcome and must never enter a canon pipeline.

## Evolution path

- Replace embedded Mission Control fixture with data conforming to
  `catalog/schemas/aurora_intelligent_ui_snapshot.schema.json`.
- Validate report provenance and stale status on every retrieval.
- Connect GUMAS only via isolated read-only exports, then review
  bounded execution separately.
- Add ACE determination receipt traversal without automatically
  materializing or publishing canonical state.
- Preserve L1 deterministic authority regardless of interface changes.
- Complete authenticated MCP/ChatGPT setup only when the operator is ready.
